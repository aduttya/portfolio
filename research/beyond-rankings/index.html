Beyond Rankings: Measuring Vendor Visibility in AI-Driven Discovery

A pilot study on why rankings break down in AI search, and a four-part model to measure visibility instead.

Ajay Yadav · Pilot study · GPT-4o · April 2026 · 27 B2B queries across 9 problem areas, 81 responses, compared with Google results.

Key findings

  1. 01AI and Google almost never send buyers to the same vendors. The average Jaccard overlap was 0.03.
  2. 0219 of 27 queries had zero overlap between the vendors GPT-4o named and the domains Google ranked.
  3. 03The same prompt returns different vendors from run to run, so a ranking is the wrong metric.

Abstract

As large language models replace traditional search engines as primary discovery interfaces, businesses face a fundamental measurement problem. LLM outputs are stochastic. The same query submitted multiple times produces different vendor sets, different framings, and different recommendations, making ranking-based metrics structurally inapplicable.

We introduce a four-dimensional probabilistic visibility model, ISIC (Inclusion, Stability, Influence, and Coverage), as the replacement measurement framework for AI-driven discovery. Across 27 queries spanning 9 problem areas and 81 GPT-4o responses, results indicate an average Jaccard overlap of 0.03, with 19 of 27 queries showing zero overlap between LLM and Google results, indicating that these two discovery channels direct buyers toward fundamentally different resources.

How the study was done

27 queries across 9 problem areas, three variants each, all taken from real buyer discussions in sales and CRM communities on Reddit, with no vendor names in the query text. Google results came from SerpAPI (US, desktop), recording the top 9 to 10 organic domains in one run per query. GPT-4o ran through the OpenAI Responses API at temperature 0 with web search on, three independent runs per query with no history, for 81 responses in total. Domains were mapped to vendors before computing the Jaccard overlap.
